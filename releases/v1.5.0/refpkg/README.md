# v1.5.0 reference package pointer

The v1.5.0 reference package (MR_RT_003: alignment, HMMs, treefile, clade definitions,
placement models, robustness grid) is tracked in place at `../../refpkg/MR_RT_003/` and is
NOT duplicated under this release directory. It carries its own `SHA256SUMS`
(`../../refpkg/MR_RT_003/SHA256SUMS`), generated by the `refpkg_checksums` Snakemake rule.

Chosen over a symlink: the repo has no existing symlinks and `git config core.symlinks` is
unset (not explicitly enabled) in this checkout, so a plain pointer file avoids any ambiguity
about symlink handling on clone/checkout.
